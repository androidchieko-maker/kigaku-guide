# 気学案内スキル

## 使い方（お客さん向け）

1. `index.html` をブラウザで開く
2. 生年月日を入力する
3. 知りたい日付を選ぶ（初期値は今日）
4. 「案内を見る」を押す

## 改修するとき

- 計算ロジックは `js/kigaku.js`
- 画面表示は `js/app.js` と `index.html` / `css/style.css`
- 説明文を変える場合は `STARS` の `short` を編集する

## 注意

- 気学は参考情報。断定的な表現は避ける
- 立春・節入りは目安日。厳密な暦が必要なら天文データ連携を検討する
